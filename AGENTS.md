## Gotchas learned the hard way
- Never define background JSX as an inline component inside render — new identity each render remounts the blurred image (visible twitching). Use a plain JSX const.
- Station images: assets/stations/*.jpg, must be ≥ ~1100px on the short side or web renders them at intrinsic size (bottom cut-off). Compress to ≤ ~600KB, JPEG only (no .avif/.webp/.png — bundler/perf). Source from Unsplash/Pexels, never Pinterest.
- Expo Go is a dead end (SDK 54 vs our 56 + no custom deep links). Android testing = EAS dev build; iOS on Windows blocked (needs paid Apple acct) — use Safari at the LAN IP for visuals, or the iOS Simulator on a Mac.
- Spotify playback API needs the user's Spotify app active on some device, and Premium.
- Spotify quota policy (confirmed 2026-07-18): extension requests are ORGANIZATIONS-ONLY since May 2025 and require an established business w/ 250k+ MAU — unreachable at launch. Dev-mode allowlist confirmed at 5 users (+ the owner account) — reserve slots for genuine music-testing testers; everyone else runs demo mode. Before public launch, build the no-API fallback: Start Drive deep-links the linked playlist into the Spotify app (spotify: URI, no auth needed) for non-allowlisted users; Cruise FM stays the visual layer.

- DONE 2026-07-25 (Disco Ball round 9 — the grid itself now turns, OTA): owner could see the light travelling but not the tiles. A sphere on its polar axis maps latitude circles onto themselves, so horizontal rings correctly DON'T move — only meridians do. KEY TRICK: a meridian's projection is the ball's own profile curve scaled horizontally by sin(longitude) plus a vertical shear proportional to that scaled x — i.e. `transform: [{skewY}, {scaleX}]`, and BOTH are in RN's native-driver SUPPORTED_TRANSFORMS allowlist (checked node_modules/react-native/Libraries/Animated/NativeAnimatedAllowlist.js). So the whole rotating grid is 24 animated views, not hundreds of animated facets. Verified by overlaying the transform output on the true projection — pixel-identical at every angle except within ~0.3° of centre, where the meridian is a straight vertical line anyway (clamp the skew to ±89° and give scaleX a 0.002 epsilon; a zero scaleX is a degenerate matrix). REJECTED on the renders, don't retry blind: (a) animating every facet as a moveable rectangle — poles break into overlapping blocks, silhouette goes ragged, because axis-aligned rects can't be the converging quads; (b) smoothing the fills so only seams move — becomes a wireframe globe and loses all mirror character.
